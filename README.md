# Monorepo
*📌 Lưu ý Đấu nối Phần cứng (Wiring Notes)**
* **Dây tím (GND):** Nối chung mass giữa mạch vi điều khiển và các thiết bị ngoại vi.
* **Dây trắng dài (ESC):** Dây tín hiệu PWM điều khiển bộ điều tốc, kết nối trực tiếp vào chân **PC6**.
* **Dây trắng ngắn (Servo):** Dây tín hiệu PWM sử dụng để điều khiển cụm Servo.
